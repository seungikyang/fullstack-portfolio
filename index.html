매일 같은 방법으로 공부하세요.

완벽하게 이해한 다음 코딩하려고 기다리지 마세요. 작은 문제를 직접 실행하고, 실제 오류를 읽고, 다시 설명하는 한 사이클이 공부입니다.

  1. 목표 한 줄 쓰기 오늘 만들 결과를 한 문장으로 정합니다.
  2. 빈칸 직접 채우기 TODO와 빈칸을 정답 없이 먼저 해결합니다.
  3. 실행해서 확인하기 화면, API 응답 또는 테스트 결과를 봅니다.
  4. 오류 첫 줄 읽기 한 번에 한 곳만 고친 뒤 다시 실행합니다.
  5. 네 가지 근거 남기기 실행 명령, 관찰 결과, 해결 오류, 코드 위치를 남깁니다.
막혔을 때 순서. 오류 첫 줄과 파일 위치 확인 → 해당 단계 README 다시 보기 → 한 곳만 수정 → 재실행 → 그래도 막히면 answers.md와 비교합니다.

공부를 취업 근거로 바꾸세요.
