# 15단계 CS 기초 (네트워크 · OS · DB 이론 · 자료구조)

## 목표

신입 기술 면접에서 단골로 나오는 CS 기초 질문에 자기 말로 대답할 수 있는 수준을 만듭니다. 코드 실력이 비슷한 두 지원자 중에서 합격을 가르는 건 보통 CS 기초입니다.

이 단계는 코드 실습이 아니라 **질문 → 자기 답안 작성 → 모범 답안 비교 → 자기 말로 다시 설명** 흐름입니다.

## 실행 방법

```bash
# 별도 설치 없음
open 15-cs-fundamentals/problems.md
```

문제마다 자기 답안을 한 단락(3~5문장)으로 적어보고, `answers.md`와 비교하세요. **모범 답안을 외우지 말고**, 차이를 보고 자기 답안을 고쳐 다시 적습니다.

## 완료 기준

- 네트워크 6문제, OS 5문제, DB 이론 5문제, 자료구조 5문제 총 21문제에 자기 답안을 작성했습니다.
- 각 답안의 마지막 줄에 "이 개념이 1~14단계의 어느 코드와 연결되는가"를 1줄 적었습니다.
- 모범 답안과 비교한 뒤 자기 답안을 한 번 이상 고쳤습니다.

## 취업 연결

SI/SW 면접에서 CS 기초는 다음 형태로 자주 나옵니다.

- "TCP와 UDP의 차이를 설명해보세요."
- "프로세스와 스레드는 무엇이 다른가요?"
- "트랜잭션 격리 수준 네 가지를 차이와 함께 설명해보세요."
- "HashMap의 평균 시간 복잡도가 O(1)인 이유는 무엇인가요?"

이 단계가 끝나면 위 같은 질문에 30초~1분 안에 답할 수 있어야 합니다.

## 학습 영역

### 네트워크

- OSI 7계층과 TCP/IP 4계층.
- TCP vs UDP. 3-way handshake.
- HTTP 메서드와 상태 코드 (이미 4단계에서 다룬 내용 심화).
- HTTPS와 TLS. 인증서.
- DNS와 도메인 해석 흐름.
- 쿠키, 세션, 토큰의 차이.

### 운영체제

- 프로세스 vs 스레드.
- 멀티스레드의 동시성과 동기화. race condition, deadlock.
- 메모리 구조. stack, heap, code, data.
- CPU 스케줄링. 선점형 vs 비선점형.
- 가상 메모리와 페이지 교체.

### DB 이론

- ACID의 네 가지 속성.
- 트랜잭션 격리 수준 (READ UNCOMMITTED, READ COMMITTED, REPEATABLE READ, SERIALIZABLE).
- 정규화 1NF, 2NF, 3NF.
- 인덱스의 구조 (B+Tree).
- NoSQL이 등장한 이유와 RDBMS와의 트레이드오프.

### 자료구조

- 배열, 연결 리스트, 스택, 큐의 시간 복잡도.
- 해시 테이블의 충돌과 해결법.
- 이진 탐색 트리와 균형 트리(AVL, Red-Black).
- 그래프 표현 (인접 행렬, 인접 리스트).
- 시간/공간 복잡도(Big-O) 개념.

## 면접에서 답할 때 주의

- "들어본 적 있다"가 아니라 **자기 예시**로 설명하세요. 예시. "TCP는 4단계 게시판 API의 HTTP 요청에서 쓰고, UDP는 게임 패킷이나 실시간 음성처럼 손실보다 지연이 더 치명적인 곳에 씁니다."
- 모르는 건 모른다고 인정하세요. 거짓 자신감은 더 큰 감점입니다.
- 정의 → 차이점 → 예시 순서로 1분 안에 끝내는 것이 모범 답안 패턴입니다.
