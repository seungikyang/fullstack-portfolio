## 문제 1. 남은 할 일 개수 계산하기

### 1단계. 개념 환기

- `filter`는 조건이 참인 배열 요소만 모아 새 배열을 만듭니다.
- 완료되지 않은 Todo는 `done`이 거짓인 항목입니다.

### 2단계. 접근 방향

- `todos`에서 완료되지 않은 항목만 남긴 뒤 그 배열의 길이를 세세요.
- 원본 `todos` 배열은 수정하지 마세요.

### 3단계. API 수준

```jsx
const remainingCount = todos
  .filter((todo) => /* 완료되지 않은 조건 */)
  .length;
```

## 문제 2. 새 Todo 추가하기

### 1단계. 개념 환기

- React state의 현재 입력값은 `input` 변수에 들어 있습니다.
- `trim`은 문자열 양끝의 공백을 제거하고 새 문자열을 반환합니다.

### 2단계. 접근 방향

- 새 객체의 `title`에 고정 문자열이 아니라 정리한 현재 입력값을 넣으세요.
- 이미 있는 빈 문자열 검사와 state 갱신 흐름은 그대로 두세요.

### 3단계. 객체 형태 수준

```jsx
const newTodo = {
  id: /* 기존 방식 유지 */,
  title: /* input을 공백 정리한 값 */,
  done: false,
};
```

## 문제 3. 완료 상태 바꾸기

### 1단계. 개념 환기

- state 배열과 그 안의 객체를 직접 바꾸지 않고 새 배열과 새 객체를 만들어야 합니다.
- 불리언 값은 논리 부정 연산자로 반대로 만들 수 있습니다.

### 2단계. 접근 방향

- `map`으로 모든 Todo를 순회하세요.
- id가 같은 Todo만 펼쳐 복사하고 `done`을 반대로 바꾸며, 나머지는 그대로 반환하세요.

### 3단계. 콜백 형태 수준

```jsx
setTodos((currentTodos) =>
  currentTodos.map((todo) =>
    todo.id === id
      ? { ...todo, done: /* 현재 값의 반대 */ }
      : todo,
  ),
);
```

## 문제 4. 입력값을 state에 저장하기

### 1단계. 개념 환기

- 입력 이벤트 객체에는 이벤트가 발생한 요소가 들어 있습니다.
- 제어 컴포넌트는 `value`와 `onChange`를 state에 연결합니다.

### 2단계. 접근 방향

- `onChange` 콜백의 매개변수를 확인하세요.
- 그 매개변수에서 입력 요소의 현재 값을 읽어 `setInput`에 전달하세요.

### 3단계. 이벤트 시그니처 수준

```jsx
<input
  value={input}
  onChange={(event) => setInput(/* 입력 요소의 현재 값 */)}
/>
```

## 문제 5. 컴포넌트에 props 연결하기

### 1단계. 개념 환기

- 부모는 함수를 props로 내려주고, 자식은 사용자 이벤트가 발생할 때 그 함수를 호출합니다.
- 목록 항목을 구분하는 id는 어느 Todo가 클릭됐는지 알려줍니다.

### 2단계. 접근 방향

- 부모에서 각 `TodoItem`에 “이 Todo의 id로 토글하는 함수”를 전달하세요.
- 자식 버튼에서는 받은 `onToggle`을 클릭 콜백으로 연결하세요.
- 렌더링 중 즉시 실행되지 않도록 함수 자체와 함수 호출을 구분하세요.

### 3단계. props 시그니처 수준

```jsx
<TodoItem
  todo={todo}
  onToggle={() => /* todo의 식별자로 부모 함수 호출 */}
/>

<button onClick={/* 부모에게서 받은 콜백 */}>완료</button>
```

3단계까지 확인한 뒤에도 막히면 마지막으로 [정답 예시와 비교하세요](./answers.md).
