# 3단계 React 배우기

## 목표

컴포넌트, props, state를 사용해 Todo 목록 앱을 만듭니다.

## 실행 방법

```bash
cd 03-react-todo
npm install
npm run dev
```

## 학습 순서

1. `src/App.jsx`에서 state가 어디에 있는지 찾습니다.
2. `src/components/TodoItem.jsx`에서 props가 어떻게 전달되는지 확인합니다.
3. `problems.md`의 순서대로 빈칸을 채웁니다.
4. 브라우저에서 할 일 추가와 완료 전환이 되는지 확인합니다.
5. 막히면 `answers.md`를 보고 다시 직접 고칩니다.

## 완료 기준

- 입력창에 적은 할 일이 목록에 추가됩니다.
- 각 Todo의 완료 상태를 바꿀 수 있습니다.
- 남은 할 일 개수가 실제 목록과 일치합니다.

## 취업 연결

React는 SI/SW 웹 프로젝트에서도 많이 쓰이는 프론트엔드 기술입니다. 신입에게는 거대한 상태관리보다 컴포넌트 분리, props 전달, state 변경 흐름을 정확히 이해하는 것이 더 중요합니다.

이 단계가 끝나면 “Todo 앱을 컴포넌트로 나누고 state로 화면을 갱신했다”고 설명할 수 있어야 합니다.

## 면접 연습

- state를 직접 수정하지 않고 `setTodos`를 쓰는 이유를 설명해보세요.
- props가 부모에서 자식으로 전달되는 흐름을 설명해보세요.
- `key` props가 필요한 이유를 설명해보세요.
