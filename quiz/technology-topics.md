## 공식 문서로 확인하기

- React state의 보존·초기화는 [React 공식 설명](https://react.dev/learn/preserving-and-resetting-state)을 기준으로 합니다.
- MongoDB 배열 질의는 [$elemMatch 문서](https://www.mongodb.com/docs/manual/reference/operator/query/elemmatch/)를 기준으로 같은 원소에 여러 조건을 적용합니다.
- SQL 순위 함수는 [PostgreSQL 윈도 함수](https://www.postgresql.org/docs/current/functions-window.html), 값 바인딩은 [node-postgres 매개변수 질의](https://node-postgres.com/features/queries)를 참고합니다.
- Node 문자·바이트 계산은 [Buffer.byteLength](https://nodejs.org/docs/latest-v24.x/api/buffer.html#static-method-bufferbytelengthstring-encoding), Java 뷰는 [List.subList](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/List.html)를 참고합니다.
- Git 작업 영역은 [git reset](https://git-scm.com/docs/git-reset), 서비스 간 접속은 [Compose 네트워크](https://docs.docker.com/compose/how-tos/networking/)를 참고합니다.

## 실행으로 확인한 범위

`npm run verify`는 전체 데이터·문서와 JavaScript 1,160문항·TypeScript 120문항·SQL 240문항을 검사합니다. TypeScript는 타입 표기를 제거한 실행 검사이고, SQL은 공통 문법을 SQLite에서 실행합니다.

추가분의 HTML·CSS·DOM 120문항은 Chromium에서 표시된 코드를 실행해 확인했습니다. Java 40문항은 JDK 17의 javac·JVM으로, React key/state 20문항은 설치된 React로 렌더링해 정답과 대조했습니다. 이 추가 검증은 루트 기본 테스트의 필수 환경에 Java나 브라우저를 추가하지 않습니다.
