### I13. GET과 POST

GET과 POST — 알맞은 설명 또는 답변 방식을 고르세요.

3. POST는 기본적으로 모든 응답이 캐시된다.
4. GET은 조회할 때마다 서버 데이터를 반드시 삭제한다.

### I65. XSS 세 종류

XSS 세 종류 — 알맞은 설명 또는 답변 방식을 고르세요.

1. 저장형은 DB 연결 오류만 뜻한다.
2. 저장형은 저장된 입력, 반사형은 응답에 반영된 입력, DOM 기반은 클라이언트의 위험한 DOM 처리에서 발생한다.
3. 반사형은 TLS 인증서 만료만 뜻한다.
4. DOM 기반은 반드시 서버 템플릿에서만 발생한다.

### I67. CSRF와 XSS

CSRF와 XSS — 알맞은 설명 또는 답변 방식을 고르세요.

1. 두 공격은 모두 DB 비밀번호를 직접 맞히는 공격이다.

4. CSRF는 사용자의 인증 상태로 원치 않는 요청을 보내고 XSS는 페이지에서 공격 스크립트를 실행한다.
