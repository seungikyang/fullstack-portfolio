## 문제 진행 방식

이 문서는 4지선다 문제입니다. 보기 네 개 중 가장 알맞은 답 하나를 고른 뒤 접힌 정답·해설을 확인하세요. 웹에서는 채점·오답 복습·진행 기록을 사용할 수 있습니다.

개인 경험을 묻던 문항은 근거 있는 답변 방식을 선택하는 문제로 바꿨습니다. 선택지의 원칙이 본인의 실제 경험을 대신하지는 않습니다.

### P01. Career Hub 한 문장 정의

Career Hub 한 문장 정의 — 알맞은 설명 또는 답변 방식을 고르세요.

1. 취업 목표·지원 기록·포트폴리오를 관리하는 풀스택 앱이다.
2. 은행 간 실시간 결제를 보장하는 금융 서비스이다.
3. Spring으로 작성된 유료 영상 스트리밍 플랫폼이다.
4. 오직 CSS만으로 구현한 운영체제이다.

3. Vue, Django, Redis만, OAuth 서버

### P03. Career Hub 핵심 기능

Career Hub 핵심 기능 — 알맞은 설명 또는 답변 방식을 고르세요.

1. 은행 송금, 영상 통화, 실시간 GPS 추적
2. 운영체제 설치, 커널 컴파일, 장치 드라이버
3. 회원가입·로그인, 지원 현황 CRUD, 포트폴리오 프로젝트 CRUD
4. 주식 주문 실행, 항공권 결제, 배송 배차

### P04. 어려웠던 점의 설명

어려웠던 점의 설명 — 알맞은 설명 또는 답변 방식을 고르세요.

1. 제공된 예시 오류를 무조건 자기 경험으로 말한다.
2. 아무 검증 없이 문제가 없어졌다고 말한다.
3. 어려움을 감추려고 허구의 성능 수치를 붙인다.
4. 재현한 문제와 본인 수정·실행 결과를 연결한다.

### P05. 검증 근거

검증 근거 — 알맞은 설명 또는 답변 방식을 고르세요.

1. 실제로 실행한 명령과 로그·확인한 기능·자동화의 한계를 제시한다.
2. 검증 명령을 읽었으면 실행했다고 말한다.
3. 빌드 성공으로 모든 외부 배포를 증명한다.
4. 테스트 결과 없이 모든 버그가 없다고 보장한다.

</details>

### P06. 한계와 다음 계획

한계와 다음 계획 — 알맞은 설명 또는 답변 방식을 고르세요.

1. 모든 요구 사항을 이미 해결했다고 말한다.
2. 현재 저장·운영 제약을 설명하고 요구에 맞는 개선 계획을 제시한다.
3. 사용하지 않은 PostgreSQL을 운영 중이라고 한다.
4. DB를 바꾸면 모든 보안 문제가 해결된다고 말한다.
