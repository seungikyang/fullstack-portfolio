# 인성·협업 질문과 STAR 답안

기술 면접에서 떨어지지 않은 사람이 인성 면접에서 떨어지는 경우가 의외로 많습니다. 협업 능력과 태도는 코드 못지않게 중요합니다.

## STAR 기법

행동 면접 답변의 표준 구조입니다. 한 답변을 다음 네 단계로 구성하세요.

- **S (Situation)**. 상황. 언제, 어디서, 누구와.
- **T (Task)**. 과제. 내가 해야 했던 일.
- **A (Action)**. 행동. 내가 구체적으로 무엇을 했는가.
- **R (Result)**. 결과. 어떻게 끝났는가. 무엇을 배웠는가.

각 단계는 1~2문장. 전체 답변은 1분 30초 안에 끝냅니다.

## 자주 나오는 인성 질문 10개

### Q1. 가장 어려웠던 경험과 그 해결 과정을 말해보세요.

```
S. ____
T. ____
A. ____
R. ____
```

힌트. SI 면접에서는 보통 기술적 어려움(특정 버그, 인수인계, 마감)을 듣고 싶어 합니다. 워크북에서 만난 실제 오류 경험을 활용하세요.

### Q2. 협업할 때 의견이 갈렸던 경험은?

```
S. ____
T. ____
A. ____
R. ____
```

힌트. "결국 내 의견대로 했다"보다 "근거로 설득하거나 절충안을 찾았다"가 더 좋습니다.

### Q3. 본인의 강점과 약점은?

```
강점. ____
근거. ____

약점. ____
보완 노력. ____
```

힌트. 약점은 정직하되 "보완 중"임을 보여야 합니다. "완벽주의"처럼 가짜 약점은 마이너스입니다.

### Q4. 새로운 기술을 배워야 할 때 어떻게 접근하나요?

```
S. ____
T. ____
A. ____
R. ____
```

힌트. 워크북의 학습 루틴(README → problems → 직접 풀기 → answers 비교 → 자기 말로 설명)이 답변의 좋은 근거입니다.

### Q5. 실수를 했을 때 어떻게 대응했나요?

```
S. ____
T. ____
A. ____
R. ____
```

힌트. 13단계 git collab의 force push 위험, 16단계의 시크릿 노출 같은 실수 시나리오를 활용할 수 있습니다.

### Q6. 마감이 임박했을 때 어떻게 일하는지 말해보세요.

```
S. ____
T. ____
A. ____
R. ____
```

### Q7. 팀에서 본인의 역할은 보통 어떤 편인가요?

```
역할 정의. ____
근거가 되는 경험. ____
```

### Q8. 1년 뒤 어떤 모습이고 싶나요?

```
1년 후 목표. ____
구체적 행동 계획. ____
```

힌트. "시니어가 되고 싶습니다"는 너무 막연합니다. "SQL과 Spring 깊이를 키우고, 사내 인수인계 시 막힘이 없는 수준이 되고 싶습니다" 같은 구체성이 좋습니다.

### Q9. 우리 회사를 왜 선택했나요?

```
회사 특성. ____
나의 학습 방향과의 연결. ____
구체적 기대. ____
```

힌트. "유명하고 안정적이라서"는 모든 지원자가 말합니다. 채용 공고의 기술 스택, 회사 블로그, 사업 영역을 조사한 흔적을 남기세요.

### Q10. 우리에게 궁금한 점이 있나요?

면접 끝에 "질문 있으세요?"가 옵니다. **반드시 한두 개 준비**하세요. "없습니다"는 관심 부족으로 해석됩니다.

예시 질문.

- 신입에게 첫 3개월 동안 어떤 업무를 맡기시나요?
- 팀의 코드 리뷰 문화는 어떤 편인가요?
- 사용하시는 주요 기술 스택이 최근 2년 안에 바뀐 부분이 있나요?
- 신입 개발자의 성장을 위해 회사가 지원하는 부분이 있나요?

## 인성 면접에서 피해야 할 답변

- "특별히 없습니다" (모든 질문에서). 작은 경험이라도 꺼내 가공하세요.
- 이전 회사·학교·동료 험담. "환경이 안 맞았다" 정도로 중립적으로.
- 거짓 경험. 디테일 추궁에서 들킵니다.
- 일관성 없는 동기. 자기소개·지원동기·1년 뒤 목표가 같은 방향을 가리켜야 합니다.

## 연습 방법

1. 한 질문에 답안 초안을 STAR로 적습니다.
2. 소리 내어 말합니다. 1분 30초를 넘기면 줄입니다.
3. 거울 보며 말합니다. 시선과 표정도 같이 봅니다.
4. 친구에게 면접관 역할을 부탁해 모의 면접을 진행합니다.
5. 녹음해 다시 듣고 "음...", "그..." 같은 군더더기 단어를 줄입니다.
