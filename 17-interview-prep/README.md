# 17단계 면접 대비 통합

## 목표

1~16단계에서 분산돼 있던 면접 질문을 한 파일로 모아, 면접 직전에 한 자리에서 복습할 수 있게 만듭니다. 자기소개·기술 면접·인성 면접 세 영역을 모두 다룹니다.

이 단계는 새 코드를 작성하지 않습니다. 대신 **자기 답안을 직접 적고, 소리 내어 말해보고, 동료에게 들려주고 피드백을 받는** 흐름이 핵심입니다.

## 실행 방법

```bash
open 17-interview-prep/interview-cards.md
```

각 카드에 자기 답안을 직접 채우세요. 답을 외우는 게 아니라, **자기 경험과 코드에 연결한 자기만의 문장**을 만드는 게 목표입니다.

## 완료 기준

- 자기소개 30초·1분·3분 버전을 모두 작성했습니다.
- 1~16단계 기술 질문에 각각 자기 답안을 적었습니다.
- 인성 질문 10개에 STAR 기법으로 답안을 작성했습니다.
- 가장 자신 있는 프로젝트 한 개를 3분 안에 설명할 수 있습니다.
- "내가 직접 고친 코드 한 줄"을 3가지 준비했습니다.

## 취업 연결

SI/SW 신입 면접에서 떨어지는 사람은 보통 코드를 못해서가 아니라 **자기 경험을 자기 말로 설명하지 못해서** 떨어집니다. 같은 프로젝트라도 "GitHub에 있어요"와 "이 기능에서 X 문제를 만났고 Y로 해결했습니다"는 평가가 완전히 다릅니다.

이 단계가 끝나면 "어떤 질문이 와도 자기 코드를 근거로 답할 수 있다"는 상태가 됩니다.

## 답변 원칙

1. **자기 코드를 근거로**. "교과서에서 봤습니다"가 아니라 "Career Hub의 server/auth.js에서 직접 다뤘습니다".
2. **30초·1분·3분 버전을 준비**. 면접관이 듣고 싶은 시간에 맞춰 답변 길이를 조정할 수 있어야 합니다.
3. **모르는 건 모른다고**. 거짓 자신감보다 "그 부분은 학습 중이지만 비슷한 X 개념과 연결됩니다"가 더 신뢰를 줍니다.
4. **숫자를 곁들이기**. "빠르게"보다 "응답 시간을 X ms에서 Y ms로 줄였습니다".
5. **소리 내어 연습**. 머릿속으로만 정리하면 실제 면접에서 막힙니다.
