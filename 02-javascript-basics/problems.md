# 2단계 문제

## 문제 1. 버튼 클릭 이벤트

`app.js`에서 버튼을 찾고 `click` 이벤트를 연결하세요.

- `querySelector`로 버튼과 메시지 영역 찾기
- 버튼 클릭 시 메시지 문구 바꾸기
- 입력한 이름이 없으면 기본 문구 보여주기

## 문제 2. 계산기 함수

두 숫자와 연산자를 받아 결과를 반환하는 `calculate` 함수를 완성하세요.

- 조건문으로 `+`, `-`, `*`, `/` 분기하기
- 나누기에서 0으로 나누는 상황 처리하기
- 결과를 화면에 출력하기

## 문제 3. 반복문으로 목록 만들기

배열에 저장된 할 일을 화면 목록으로 렌더링하세요.

- 입력값을 배열에 추가하기
- 반복문으로 `li` 태그 만들기
- 입력창을 다시 비우기
