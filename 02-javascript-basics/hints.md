## 문제 1. 버튼 클릭 이벤트

### 1단계. 개념 환기

- DOM 요소를 찾은 뒤 이벤트 리스너를 등록하면 사용자 동작에 반응할 수 있습니다.
- 입력 요소의 현재 문자열은 `value` 속성에서 읽습니다.
- 빈 입력인지 확인할 때 앞뒤 공백도 함께 처리해야 합니다.

### 2단계. 접근 방향

- 버튼, 이름 입력창, 메시지 영역을 각각 변수에 저장하세요.
- 클릭 콜백 안에서 이름을 읽고, 빈 값과 입력된 값의 두 경우를 나누세요.
- 마지막에 메시지 영역의 텍스트만 바꾸세요.

### 3단계. API 수준

```js
const element = document.querySelector("CSS 선택자");

button.addEventListener("click", () => {
  const value = input.value.trim();
  message.textContent = /* 조건에 따른 문구 */;
});
```

## 문제 2. 계산기 함수

### 1단계. 개념 환기

- 입력창에서 읽은 값은 문자열이므로 계산 전에 숫자로 변환해야 합니다.
- 함수의 `return`은 계산 결과를 호출한 곳으로 돌려줍니다.
- 0으로 나누기는 일반 계산보다 먼저 예외 조건을 확인해야 합니다.

### 2단계. 접근 방향

- 연산자별 분기를 하나씩 만들고 각 분기에서 두 인자를 계산하세요.
- 나눗셈 분기 안에서 두 번째 숫자가 0인지 먼저 확인하세요.
- 함수 호출 결과를 받은 뒤 출력 요소의 텍스트로 표시하세요.

### 3단계. 함수 시그니처 수준

```js
function calculate(left, operator, right) {
  if (operator === "연산자") {
    return /* left와 right를 사용한 계산 */;
  }
}

const left = Number(leftInput.value);
```

## 문제 3. 반복문으로 목록 만들기

### 1단계. 개념 환기

- 배열은 할 일 데이터의 현재 상태를 보관합니다.
- 화면 목록은 배열을 순회하며 DOM 요소를 만들어 다시 그릴 수 있습니다.
- 새 값을 배열에 넣은 뒤 렌더링 함수를 다시 호출해야 화면도 갱신됩니다.

### 2단계. 접근 방향

- 입력값을 읽고 빈 값인지 확인한 뒤 배열에 추가하세요.
- 렌더링 시작 시 기존 목록을 비우고 배열의 각 항목마다 목록 요소를 만드세요.
- 추가와 렌더링이 끝난 뒤 입력창 값을 비우세요.

### 3단계. API 수준

```js
todos.push(/* 입력한 할 일 */);

todos.forEach((todo) => {
  const item = document.createElement(/* 목록 항목 태그 */);
  item.textContent = todo;
  list.appendChild(item);
});
```

3단계까지 확인한 뒤에도 막히면 마지막으로 [정답 예시와 비교하세요](./answers.md).
