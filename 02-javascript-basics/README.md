# 2단계 JavaScript 기초

## 목표

변수, 조건문, 반복문, 함수, DOM 이벤트를 이용해 버튼 반응과 간단한 계산기를 만듭니다.

## 학습 순서

1. `starter/index.html`에서 버튼과 입력 요소의 역할을 확인합니다.
2. `starter/app.js`의 빈칸을 채워 이벤트 연결과 계산 기능을 완성합니다.
3. 브라우저 개발자 도구의 Console 탭에서 오류를 읽고 수정합니다.
4. 막히면 `answers.md`를 보고 다시 직접 고칩니다.

## 완료 기준

- 버튼을 누르면 환영 메시지가 바뀝니다.
- 숫자 두 개를 입력하고 더하기, 빼기, 곱하기, 나누기 결과를 볼 수 있습니다.
- 할 일 입력 후 추가 버튼을 누르면 목록에 항목이 추가됩니다.

## 취업 연결

JavaScript 기본기는 프론트엔드와 백엔드 모두에서 계속 쓰입니다. SI/SW 신입 과제에서는 버튼 클릭, 입력값 처리, 배열 반복, 함수 분리 같은 기본기가 자주 확인됩니다.

이 단계가 끝나면 “사용자 입력을 읽고 이벤트에 맞춰 화면을 바꿨다”고 설명할 수 있어야 합니다.

## 면접 연습

### `const`, `let`을 언제 나눠 쓰는지 설명해보세요.

재할당이 필요 없는 값은 기본적으로 `const`를 사용합니다. 반복문 카운터나 계산 결과처럼 값이 바뀌어야 하는 변수에는 `let`을 사용합니다. 이렇게 나누면 의도치 않은 재할당을 줄이고 코드의 의도를 더 명확히 표현할 수 있습니다.

### `Number()`가 필요한 이유를 설명해보세요.

HTML 입력값은 숫자처럼 보여도 JavaScript에서는 문자열로 들어옵니다. 예를 들어 `"1" + "2"`는 `3`이 아니라 `"12"`가 됩니다. 계산기처럼 산술 연산이 필요한 경우 `Number()`로 문자열을 숫자로 변환해야 정확한 계산 결과를 얻을 수 있습니다.

### 배열에 값을 추가한 뒤 화면을 다시 그리는 이유를 설명해보세요.

배열 데이터가 바뀌어도 DOM 화면은 자동으로 바뀌지 않습니다. 새 할 일을 배열에 추가한 뒤 목록을 다시 렌더링해야 데이터와 화면이 일치합니다. 이 과정은 "상태가 바뀌면 UI도 그 상태를 기준으로 다시 만든다"는 프론트엔드의 기본 흐름입니다.
