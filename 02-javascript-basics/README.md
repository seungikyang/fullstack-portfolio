## 목표

변수, 조건문, 반복문, 함수, DOM 이벤트를 이용해 버튼 반응과 간단한 계산기를 만듭니다.

## 기술을 쓰는 이유와 동작 흐름

처음 보는 용어는 [전체 기술 안내서](../technology-guide.md)와 함께 읽으세요. 아래 흐름은 실습을 이해하기 위한 안내이며, 빈칸과 완료 체크는 직접 진행합니다.

| 기술 | 무엇이고, 왜 필요한가요? | 이 실습에서는 어떻게 쓰나요? |
| --- | --- | --- |
| JavaScript | 사용자 행동에 따라 계산하고 데이터를 바꾸는 언어입니다. HTML·CSS만으로 표현하기 어려운 동작을 담당합니다. | [app.js](./starter/app.js)에 인사, 계산기, 할 일 처리 함수가 있습니다. |
| DOM | 브라우저가 HTML을 프로그램에서 읽고 바꿀 수 있게 만든 구조입니다. 입력값을 읽고 결과를 표시할 연결점입니다. | [index.html](./starter/index.html)의 요소를 JavaScript가 찾아 사용합니다. |
| 이벤트 | 클릭·입력처럼 브라우저에서 발생한 일을 알리는 신호입니다. 필요한 순간에만 처리 함수를 실행하게 합니다. | `app.js`에서 각 버튼에 동작을 연결합니다. |
| 배열과 함수 | 배열은 여러 값을 순서대로 보관하고, 함수는 반복할 작업에 이름을 붙입니다. 데이터와 화면 처리의 역할을 나누기 위해 씁니다. | 할 일 배열을 `renderTodos`가 읽어 화면 목록을 만듭니다. |

**계산 버튼의 처리 순서:** 입력값 읽기 → 숫자로 변환 → 계산 함수 호출 → 결과를 DOM에 표시. 이 작업은 브라우저 안에서 끝나며 데이터를 서버로 보내지 않습니다.

**직접 관찰하기:** 계산 함수에 개발자 도구 중단점(실행을 잠시 멈추는 표시)을 걸어 입력값과 계산 결과를 비교하세요. 할 일을 추가한 뒤 새로고침하면 목록이 어떻게 되는지도 확인합니다. 다음 React 단계에서는 데이터가 바뀔 때 화면을 갱신하는 작업을 React가 도와줍니다.

## 실행 방법

빈칸을 채운 뒤 운영체제의 파일 탐색기에서 `starter/index.html`을 더블 클릭하거나 [HTML 실행 지도](../index.html#run-02)의 화면 열기를 누릅니다. 브라우저 개발자 도구의 Console을 함께 열어 실제 오류부터 읽으세요.

## 학습 순서

1. `starter/index.html`에서 버튼과 입력 요소의 역할을 확인합니다.
2. `starter/app.js`의 빈칸을 채워 이벤트 연결과 계산 기능을 완성합니다.
3. 브라우저 개발자 도구의 Console 탭에서 오류를 읽고 수정합니다.
4. 막히면 `hints.md`의 1단계부터 3단계까지 필요한 만큼만 봅니다.
5. 그래도 해결되지 않을 때만 `answers.md`와 비교하고 다시 직접 고칩니다.

## 완료 기준

- 버튼을 누르면 환영 메시지가 바뀝니다.
- 숫자 두 개를 입력하고 더하기, 빼기, 곱하기, 나누기 결과를 볼 수 있습니다.
- 할 일 입력 후 추가 버튼을 누르면 목록에 항목이 추가됩니다.

완료로 표시하기 전 [학습 근거 4종](../student-checklist.md#단계마다-남길-4종-근거)에 브라우저 실행 경로, 동작 결과, Console 오류와 수정, 바꾼 함수 위치를 기록합니다.

## 취업 연결

JavaScript 기본기는 프론트엔드와 백엔드 모두에서 계속 쓰입니다. SI/SW 신입 과제에서는 버튼 클릭, 입력값 처리, 배열 반복, 함수 분리 같은 기본기가 자주 확인됩니다.

이 단계가 끝나면 “사용자 입력을 읽고 이벤트에 맞춰 화면을 바꿨다”고 설명할 수 있어야 합니다.

## 면접 연습

### `const`, `let`을 언제 나눠 쓰는지 설명해보세요.

재할당이 필요 없는 값은 기본적으로 `const`를 사용합니다. 반복문 카운터나 계산 결과처럼 값이 바뀌어야 하는 변수에는 `let`을 사용합니다. 이렇게 나누면 의도치 않은 재할당을 줄이고 코드의 의도를 더 명확히 표현할 수 있습니다.

### `Number()`가 필요한 이유를 설명해보세요.

HTML 입력값은 숫자처럼 보여도 JavaScript에서는 문자열로 들어옵니다. 예를 들어 `"1" + "2"`는 `3`이 아니라 `"12"`가 됩니다. 계산기처럼 산술 연산이 필요한 경우 `Number()`로 문자열을 숫자로 변환해야 정확한 계산 결과를 얻을 수 있습니다.

### 배열에 값을 추가한 뒤 화면을 다시 그리는 이유를 설명해보세요.

배열 데이터가 바뀌어도 DOM 화면은 자동으로 바뀌지 않습니다. 새 할 일을 배열에 추가한 뒤 목록을 다시 렌더링해야 데이터와 화면이 일치합니다. 이 과정은 "상태가 바뀌면 UI도 그 상태를 기준으로 다시 만든다"는 프론트엔드의 기본 흐름입니다.
