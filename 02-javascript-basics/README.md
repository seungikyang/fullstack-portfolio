# 2단계 JavaScript 기초

## 목표

변수, 조건문, 반복문, 함수, DOM 이벤트를 이용해 버튼 반응과 간단한 계산기를 만듭니다.

## 학습 순서

1. `starter/index.html`에서 버튼과 입력 요소의 역할을 확인합니다.
2. `starter/app.js`의 빈칸을 채워 이벤트 연결과 계산 기능을 완성합니다.
3. 브라우저 개발자 도구의 Console 탭에서 오류를 읽고 수정합니다.
4. 막히면 `answers.md`를 보고 다시 직접 고칩니다.

## 완료 기준

- 버튼을 누르면 환영 메시지가 바뀝니다.
- 숫자 두 개를 입력하고 더하기, 빼기, 곱하기, 나누기 결과를 볼 수 있습니다.
- 할 일 입력 후 추가 버튼을 누르면 목록에 항목이 추가됩니다.

## 취업 연결

JavaScript 기본기는 프론트엔드와 백엔드 모두에서 계속 쓰입니다. SI/SW 신입 과제에서는 버튼 클릭, 입력값 처리, 배열 반복, 함수 분리 같은 기본기가 자주 확인됩니다.

이 단계가 끝나면 “사용자 입력을 읽고 이벤트에 맞춰 화면을 바꿨다”고 설명할 수 있어야 합니다.
