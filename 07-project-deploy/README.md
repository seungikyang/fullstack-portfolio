## 실행 방법

```bash
cd 07-project-deploy
npm install

```

- `src/server.js`는 API 서버와 정적 파일 제공을 담당합니다.
- `public/index.html`은 화면 구조를 담당합니다.
- `public/app.js`는 API 호출과 화면 렌더링을 담당합니다.
- `public/styles.css`는 최종 프로젝트 화면 스타일을 담당합니다.

## 면접 연습

### 브라우저에서 버튼을 누른 뒤 서버까지 어떤 순서로 요청이 이동하는지 설명해보세요.

사용자가 버튼을 누르면 브라우저에서 클릭 이벤트가 발생합니다. 프론트엔드 JavaScript가 입력값을 읽고 `fetch`로 API 요청을 보냅니다. Express 서버는 라우터에서 요청을 받아 데이터를 처리한 뒤 JSON 응답을 보내고, 브라우저는 응답을 받아 화면을 다시 렌더링합니다.

### 배포 환경에서 `PORT`를 직접 고정하면 안 되는 이유를 설명해보세요.

Render, fly.io, Heroku 같은 배포 환경은 실행 시점에 사용할 포트를 환경 변수로 주입하는 경우가 많습니다. 코드에서 포트를 `4000`처럼 고정하면 플랫폼이 열어준 포트와 맞지 않아 외부 접속이 실패할 수 있습니다. 그래서 `process.env.PORT || 기본값` 형태로 운영 환경의 포트를 우선 사용해야 합니다.

### 메모리 저장소와 DB 저장소의 차이를 설명해보세요.

메모리 저장소는 빠르고 간단하지만 서버 재시작 시 데이터가 사라지고 여러 서버가 같은 데이터를 공유하기 어렵습니다. DB 저장소는 별도 저장 시스템에 데이터를 보존하므로 재시작 후에도 유지되고 검색, 정렬, 동시성 처리에 유리합니다. 학습 초기에는 메모리 배열로 흐름을 익히고, 실제 서비스에는 DB를 사용해야 합니다.
