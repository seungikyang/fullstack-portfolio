# 7단계 프로젝트 및 배포

## 목표

지금까지 배운 내용을 합쳐 미니 블로그 프로젝트를 완성하고 배포 준비까지 경험합니다.

## 실행 방법

```bash
cd 07-project-deploy
npm install
npm run dev
```

브라우저에서 `http://localhost:4300`을 열어 확인하세요.

막히면 `answers.md`를 보고 다시 직접 고칩니다.

## 프로젝트 구성

- `src/server.js`는 API 서버와 정적 파일 제공을 담당합니다.
- `public/index.html`은 화면 구조를 담당합니다.
- `public/app.js`는 API 호출과 화면 렌더링을 담당합니다.
- `public/styles.css`는 최종 프로젝트 화면 스타일을 담당합니다.
- `deploy-checklist.md`는 배포 전 확인 목록입니다.

## 완료 기준

- 게시글 목록이 화면에 보입니다.
- 새 게시글을 작성하면 목록 맨 위에 추가됩니다.
- 서버와 프론트엔드가 같은 포트에서 함께 동작합니다.
- 배포 전 환경 변수와 실행 명령을 설명할 수 있습니다.

## 취업 연결

마지막 단계는 포트폴리오로 보여줄 수 있는 작은 완성 프로젝트입니다. 기능이 작아도 실행 방법, 주요 기능, 배포 주소, 배운 점을 README에 정리하면 면접에서 설명하기 좋아집니다.

이 단계가 끝나면 “프론트엔드 화면에서 API를 호출하고 서버를 배포 가능한 형태로 구성했다”고 설명할 수 있어야 합니다.

## 면접 연습
