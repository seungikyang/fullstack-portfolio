# 배포 체크리스트

## Render 서버 배포

- [ ] GitHub 저장소에 프로젝트를 올렸습니다.
- [ ] Render에서 Web Service를 만들었습니다.
- [ ] Build Command를 `npm install`로 설정했습니다.
- [ ] Start Command를 `npm start`로 설정했습니다.
- [ ] `PORT`는 Render가 자동 제공하므로 코드에서 `process.env.PORT`를 사용합니다.
- [ ] 배포 후 `/api/health` 주소가 정상 응답합니다.

## Vercel 프론트엔드 배포를 따로 하는 경우

- [ ] 프론트엔드와 백엔드 주소가 분리되는지 확인했습니다.
- [ ] API 주소를 환경 변수로 관리할 계획을 세웠습니다.
- [ ] 브라우저 CORS 오류가 나면 서버의 CORS 설정을 확인합니다.

## 배포 후 점검

- [ ] 첫 화면이 깨지지 않습니다.
- [ ] 게시글 목록 조회가 됩니다.
- [ ] 게시글 작성이 됩니다.
- [ ] 서버 로그에서 오류를 읽을 수 있습니다.
