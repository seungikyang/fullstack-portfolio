# 1단계 HTML과 CSS 배우기

[HTML 목차](../index.html) · [문제 풀기](./problems.md) · [막혔을 때 정답 비교](./answers.md) · [완료 체크](../student-checklist.md)

## 목표

자기소개 페이지를 만들며 HTML 태그와 CSS 배치를 익힙니다.

## 학습 순서

1. `starter/index.html`에서 빈칸을 채워 페이지 구조를 완성합니다.
2. `starter/styles.css`에서 색상, 간격, flexbox, grid 빈칸을 채웁니다.
3. 브라우저로 `starter/index.html`을 열어 화면을 확인합니다.
4. 막히면 `answers.md`를 보고 다시 직접 고칩니다.

## 완료 기준

- 이름, 소개 문장, 관심 기술, 연락처가 보입니다.
- 프로필 영역이 가로 또는 세로로 자연스럽게 배치됩니다.
- 기술 카드가 grid로 정렬됩니다.
- 모바일 화면에서도 내용이 잘리지 않습니다.

완료로 표시하기 전 [학습 근거 4종](../student-checklist.md#단계마다-남길-4종-근거)에 브라우저 실행 경로, 화면 관찰 결과, 해결한 오류, 수정한 HTML/CSS 위치를 기록합니다.

## 취업 연결

SI/SW 신입 화면 구현 과제에서는 복잡한 디자인보다 HTML 구조, CSS 배치, 반응형 처리, 기본 접근성을 보는 경우가 많습니다.

이 단계가 끝나면 “자기소개 페이지를 시맨틱 태그와 반응형 CSS로 만들었다”고 설명할 수 있어야 합니다.

## 면접 연습

### `div`만 쓰지 않고 `header`, `main`, `section`을 쓴 이유를 설명해보세요.

`div`는 의미가 없는 범용 컨테이너라서 문서 구조를 파악하기 어렵습니다. `header`, `main`, `section` 같은 시맨틱 태그를 쓰면 브라우저, 검색 엔진, 스크린 리더가 페이지의 역할을 더 잘 이해할 수 있습니다. 그래서 화면을 단순히 보이게 만드는 것뿐 아니라 구조와 접근성까지 고려하기 위해 사용했습니다.

### flexbox와 grid를 각각 어디에 썼는지 설명해보세요.

flexbox는 한 방향 정렬에 적합해서 프로필 영역처럼 이미지와 텍스트를 나란히 배치하는 곳에 사용했습니다. grid는 행과 열을 동시에 다루기 좋아서 기술 카드 목록처럼 여러 항목을 격자로 정렬하는 곳에 사용했습니다. 즉, flexbox는 축 중심 배치, grid는 2차원 레이아웃에 적합하다고 설명할 수 있습니다.

### 모바일 화면에서 레이아웃을 바꾼 이유를 설명해보세요.

데스크톱에서 가로로 넓게 보이는 레이아웃은 모바일에서는 내용이 좁아지거나 잘릴 수 있습니다. 미디어 쿼리로 카드나 프로필 영역을 세로 배치로 바꾸면 작은 화면에서도 읽기 쉽고 스크롤 흐름이 자연스러워집니다. 반응형 처리는 사용자의 기기 크기에 맞춰 같은 정보를 안정적으로 보여주기 위한 작업입니다.
