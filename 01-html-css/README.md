# 1단계 HTML과 CSS 배우기

[HTML 목차](../index.html) · 학습 흐름. [문제 풀기](./problems.md) → [단계별 힌트](./hints.md) → [정답 비교](./answers.md) → [완료 체크](../student-checklist.md)

## 목표

자기소개 페이지를 만들며 HTML 태그와 CSS 배치를 익힙니다.

## 기술을 쓰는 이유와 동작 흐름

처음 보는 용어는 [전체 기술 안내서](../technology-guide.md)와 함께 읽으세요. 아래 흐름은 실습을 이해하기 위한 안내이며, 빈칸과 완료 체크는 직접 진행합니다.

| 기술 | 무엇이고, 왜 필요한가요? | 이 실습에서는 어떻게 쓰나요? |
| --- | --- | --- |
| HTML | 제목·문단·목록처럼 내용의 역할을 표시하는 문서 언어입니다. 화면을 꾸미기 전에 읽을 순서를 정합니다. | [index.html](./starter/index.html)의 제목과 영역을 브라우저가 문서 구조로 읽습니다. |
| CSS | HTML 요소의 색·간격·배치를 정하는 규칙입니다. 같은 내용을 다양한 화면 크기에 맞게 보여줍니다. | [styles.css](./starter/styles.css)가 HTML의 `class` 이름과 연결됩니다. |
| Flexbox·Grid | 각각 한 방향 정렬과 행·열 배치를 돕는 CSS 기능입니다. 요소마다 위치를 직접 계산하는 부담을 줄입니다. | 같은 CSS에서 프로필과 기술 목록의 배치를 나눠 연습합니다. |
| 미디어 쿼리 | 화면 너비 같은 조건에 따라 CSS를 적용하는 문법입니다. 좁은 화면에서도 내용을 읽을 수 있게 합니다. | CSS 아래쪽의 너비 조건에서 프로필 배치가 달라지도록 구성합니다. |

**화면이 만들어지는 순서:** 브라우저가 HTML을 읽음 → 연결된 CSS를 읽음 → 요소별 크기와 위치를 계산함 → 화면에 표시함. 이 단계의 자기소개 페이지에는 API 서버가 필요하지 않습니다.

**직접 관찰하기:** 개발자 도구의 Elements(요소)에서 프로필을 선택한 뒤 창 너비를 바꿔 보세요. 글 내용은 그대로인데 어느 CSS 규칙이 바뀌는지 찾아 설명합니다. 이 구조·배치 원리는 3단계 React 화면과 Career Hub의 화면에도 이어집니다.

## 실행 방법

빈칸을 채운 뒤 운영체제의 파일 탐색기에서 `starter/index.html`을 더블 클릭하거나 [HTML 실행 지도](../index.html#run-01)의 화면 열기를 누릅니다. 브라우저 개발자 도구에서 데스크톱과 모바일 너비를 모두 확인하세요.

## 학습 순서

1. `starter/index.html`에서 빈칸을 채워 페이지 구조를 완성합니다.
2. `starter/styles.css`에서 색상, 간격, flexbox, grid 빈칸을 채웁니다.
3. 브라우저로 `starter/index.html`을 열어 화면을 확인합니다.
4. 오류가 있으면 브라우저 개발자 도구에서 파일과 줄을 먼저 확인합니다.
5. 막히면 `hints.md`의 1단계부터 3단계까지 필요한 만큼만 봅니다.
6. 그래도 해결되지 않을 때만 `answers.md`와 비교하고 다시 직접 고칩니다.

## 완료 기준

- 이름, 소개 문장, 관심 기술, 연락처가 보입니다.
- 프로필 영역이 가로 또는 세로로 자연스럽게 배치됩니다.
- 기술 카드가 grid로 정렬됩니다.
- 모바일 화면에서도 내용이 잘리지 않습니다.

완료로 표시하기 전 [학습 근거 4종](../student-checklist.md#단계마다-남길-4종-근거)에 브라우저 실행 경로, 화면 관찰 결과, 해결한 오류, 수정한 HTML/CSS 위치를 기록합니다.

## 취업 연결

SI/SW 신입 화면 구현 과제에서는 복잡한 디자인보다 HTML 구조, CSS 배치, 반응형 처리, 기본 접근성을 보는 경우가 많습니다.

이 단계가 끝나면 “자기소개 페이지를 시맨틱 태그와 반응형 CSS로 만들었다”고 설명할 수 있어야 합니다.
